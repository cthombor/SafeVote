# Dublin West

Dataset containing ranked votes for the Dublin West constituency in
2002, Ireland.

## Usage

``` r
data(dublin_west)
```

## Format

A data frame with 29988 observations and 9 candidates. Each record
corresponds to one ballot with candidates being ranked between 1 and 9
with zeros allowed.
