# Dublin West vote count

Dublin West vote count

## Usage

``` r
dublin_west_vote_count
```

## Format

A copy of the output of the stv() method of vote 2.5-2, when it produces
a complete ranking of candidates standing in the Dublin West election of
2002. The runtime of that count is approximately 2 minutes on my laptop,
making it painful to regress against vote::stv(dublin_west,
complete.ranking = TRUE).
